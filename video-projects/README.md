## 📥 Import to Capcut

### Step 1: Create Project
1. Open Capcut app
2. Tap "New Project"
3. Select "9:16" aspect ratio (vertical)
4. Set resolution to 1080x1920

### Step 2: Import Assets
1. Tap "Import" → Select generated images
2. Add images to timeline in order:
   - title_market_update.png (3s)
   - stock_card_green.png (7s) - TSLA
   - stock_card_red.png (7s) - NVDA
   - stock_card_red.png (7s) - AMZN
   - vix_warning.png (4s)
   - title_market_update.png (2s) - Outro

### Step 3: Add Text Overlays
- Use timeline JSON for exact text placement
- Match fonts (Inter Bold/Regular)
- Apply animations (slide up, fade in)

### Step 4: Add Effects
- Apply glow effects to stock cards
- Add pulse/shake to VIX warning
- Use zoom_slow on title

### Step 5: Add Audio
- Import background music
- Set volume to 30%
- Apply fade in/out

### Step 6: Export
1. Tap "Export"
2. Resolution: 1080p
3. Format: MP4
4. Quality: High
5. Export to camera roll
