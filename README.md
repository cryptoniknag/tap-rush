# Tap Rush

A fast-paced tapping game optimized for Telegram and mobile browsers.

## Play Now
🎮 **[Play Tap Rush](https://0xnickhil.github.io/tap-rush)**

## How to Play
- Tap the red button as fast as you can!
- Build combos by tapping quickly (within 500ms)
- Combos give bonus points: x2, x3, x5 multipliers
- You have 30 seconds - beat your high score!

## Features
- ⏱️ 30-second time attack
- 🔥 Combo system with multipliers
- 📱 Mobile-optimized for Telegram
- 🏆 High score saved locally
- ✨ Smooth animations and visual feedback

## Tech Stack
- HTML5
- CSS3 (with mobile optimizations)
- Vanilla JavaScript
- No external dependencies
